# Portfolio de Proyectos – Data Science & Inteligencia Artificial

Este repositorio reúne proyectos desarrollados durante mi especialización en **Análisis de Datos e Inteligencia Artificial**, donde aplico técnicas de machine learning, procesamiento de lenguaje natural y visión por computadora para resolver distintos problemas de datos.

## Proyectos

### Sistema de Recomendación de Productos
Desarrollo y evaluación de distintos enfoques de sistemas de recomendación (KNN, filtrado colaborativo y factorización matricial mediante SVD) para sugerir productos a usuarios a partir de sus valoraciones.

**Tecnologías:** Python, Scikit-learn, Surprise  
**Área:** Recommender Systems

---

### Detección de Veracidad en Declaraciones Políticas
Clasificación automática de declaraciones políticas según su nivel de veracidad utilizando técnicas de procesamiento de lenguaje natural aplicadas al LIAR Dataset.

**Tecnologías:** Python, NLP, TF-IDF, Scikit-learn  
**Área:** Natural Language Processing

---

### Detección de Casco de Seguridad con Visión por Computadora
Modelo de deep learning para detectar automáticamente el uso de casco de seguridad en imágenes de obras de construcción.

**Tecnologías:** Python, TensorFlow, CNN  
**Área:** Computer Vision

---

## Tecnologías utilizadas
- Python
- Pandas / NumPy
- Scikit-learn
- TensorFlow / Keras
- NLP
- Computer Vision

## Objetivo
El objetivo de este repositorio es documentar proyectos prácticos donde aplico metodologías de ciencia de datos para analizar información, construir modelos predictivos y desarrollar soluciones basadas en inteligencia artificial.
