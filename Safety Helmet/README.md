# Detección de Casco de Seguridad con Visión por Computadora

## Descripción

Este proyecto desarrolla un modelo de visión por computadora para
detectar automáticamente si un trabajador utiliza casco de seguridad en
imágenes de obras de construcción.

Se entrena una red neuronal convolucional (CNN) para realizar una
clasificación binaria (con casco / sin casco) utilizando el dataset
SHEL5K. El trabajo incluye preprocesamiento de imágenes,
recategorización de clases y técnicas de data augmentation.

El modelo resultante demuestra que es posible implementar sistemas
automatizados de monitoreo de seguridad laboral mediante deep learning
aplicado a imágenes.

## Tecnologías utilizadas

-   Python
-   TensorFlow / Keras
-   OpenCV
-   NumPy
-   Matplotlib

## Estructura del repositorio

-   data/ → dataset de imágenes\
-   notebooks/ → entrenamiento del modelo\
-   models/ → modelo entrenado\
-   results/ → métricas y visualizaciones

## Objetivo académico

Proyecto realizado en el marco de la especialización en **Análisis de
Datos e Inteligencia Artificial**, aplicando técnicas de deep learning y
visión por computadora.
